## 2. 경계·불변식 (필수)

- **M17-1** 세션 분류는 결정표 하나로 정한다(`outcome17` — 요약기 · selftest 공유). 끝 상태 판정은 배수 창 뒤 DB + PG 원장으로만 한다(응답은 교차 확인 — 어긋남은 G1 실패).
- **M17-2** 판정 숫자(문턱 · 비율 · 주입 · 세션 수 · 무효 사유)는 측정 전 고정 커밋 뒤 바꾸지 않는다(바꾸면 그 캠페인 무효 · 재합의).
- **M17-3** 무효 회차는 판정에 들어가지 않는다 · 무효 사유는 회차 폴더에 남는다 · 조용한 누락 0(계획 세션 수 = 분류 세션 수 · 종류별).
- **M17-4** 회차는 DB · 앱 · PG 상태를 다른 회차와 나누지 않는다(compose down · 볼륨 초기화 · PG reset + 주입 재설정 · 시드 대조).
- **M17-5** 보상 경로 '거부'는 하네스가 만든 실제 길(결제는 마감 안 · 확정이 늦음)로만 만든다 — 서버 시계 조작 · DB 직접 수정으로 만들지 않는다.
- **M17-6** G1 '고아 0'이 '거부가 없어서' 생기지 않는다 — 회차마다 지연 확정 세션의 거부 수 > 0 · 확정 안 보냄 세션의 안전망 종결 수 > 0을 유효 조건으로 둔다.
- **앱 코드 변경 없음**(main-app · mock-pg) — 하네스에 앱 변경이 필요해지면 멈추고 보고(§4 계획 밖 파일).
- 범위 밖: 기본 모드 교체 커밋 · 거부 기록 · 작업 정리 배치(Q8) · 다중 앱 인스턴스 경합 · 실제 PG.
