- 대응 질문: Q5 "화면엔 빈자리였는데 누르니 이미 팔렸다면?"
- 선행: ADR-015(좌석 상태의 원천)

## 문제

좌석맵은 조회 시점의 스냅샷이다. 20만 명이 좌석맵을 반복 조회하면 DB 부하가 크고, 캐시를 두면 불일치가 커진다.

## 가설

- 불일치 자체는 없앨 수 없다. 관리할 것은 불일치의 **크기**(얼마나 오래된 화면인가)와 **결과**(선점 실패 응답이 빠르고 명확한가)다.

## 선택지 후보

- 캐시 없음 / 짧은 TTL 캐시 / 이벤트 기반 갱신 / 좌석 상태 푸시
- 측정: 조회 TPS·p99, "빈자리로 보였는데 선점 실패" 비율
