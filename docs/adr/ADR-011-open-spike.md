# ADR-011: 오픈 정각 트래픽 폭주 (Q4)
> 번호 이동(2026-10-04): 임계 구역 길이·락 보유 시간을 새 ADR-004로 넣으며 기존 ADR-004~010을 005~011로 옮겼다 — 이 문서의 번호 참조는 새 번호다.

- 상태: 가설 (Hypothesis) — 미측정
- 대응 질문: Q4 "오픈 정각에 20만 명이 동시에 들어왔다면?"
- 선행: ADR-003, ADR-010

## 문제

동접 20만 명이 한꺼번에 선점 API를 두드리면 DB 커넥션 풀과 락 대기에서 무너진다.

## 가설

- 대기열 없이 오픈하면 선점 API의 p99와 에러율이 급증하고, 커넥션 풀 고갈이 정합성 문제보다 먼저 온다.

## 선택지 후보

- 대기열 (Redis Sorted Set) + 입장 토큰 초당 N명 (100 / 300 / 1,000)
- 레이트 리미터 (→ ops 04)
- 측정: 입장 속도별 TPS · p99 · 에러율 · 매진 시간
