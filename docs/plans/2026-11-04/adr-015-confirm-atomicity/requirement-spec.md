## 1. 목표·대상 (필수)

`seat-reservation-lab`의 A(sweep) + 기본 조합 확정 경로에 **확인과 전환을 원자적으로 만드는 네 모드(①~④)와 A′ 배치 · V12 부분 유니크 인덱스 · V13 연장 표지 열 · (③ 선택 위치) V14 트리거**를 손잡이 `seat.confirm.mode`(기본 `current` = 지금 코드 그대로)로 넣고, **재현 테스트에서 대조군은 이중 결과 ≥ 1 · 새 모드는 0**을 보인 뒤, **.164 확정 경합 부하로 다섯 모드를 비교해 측정 전에 고정한 규칙으로 기본값을 정하고 ADR-015 §실험 결과 · §결정을 쓰면 끝**.

## 2. 경계·불변식 (필수)

- **새 동작 불변식 N1~N11** = ADR-015 §설계-6 표 그대로(확정 성공 ⇒ 홀드 1행 삭제 + 좌석 `HELD→RESERVED` 1행 + 예약 1건 · 한 홀드 많아야 1회 확정 · 남의 활성 홀드 좌석을 `RESERVED`로 만들지 않음 · 진 확정은 계약 코드 5xx 0 · 배치 감소 = 실제 지운 행 · 같은 좌석 CONFIRMED ≤ 1(DB) · 조합 밖 기동 거부 + 스키마 무변경 · 잠금 순서 쿼터→홀드→좌석 · ④ 첫 연장만 · 연장 잃음 0 · 새 모드는 V12 유효일 때만).
- **보존(기존 동작)**: 손잡이를 주지 않으면(`current`) 지금 JPA 확정 · JPA 배치의 SQL · 판정 · 순서 그대로 — 더하는 것은 유니크 위반 매핑(409 + 지표)과 관측 지표 `converted_after_expiry{clock=app}` 둘뿐(§설계-3 공통 규칙). A 에러 순서(404→403→409 HOLD_EXPIRED→409 SEAT_NOT_HELD) · 만료 정각 = 만료 · 카운터 실제 값 정의(V6 · 판정기) 그대로.
- **범위 밖 경로 무변경**: 선점 · 정리 ① · B·C·D 확정/배치(`LazyConfirmProcess` · `LazyExpiryBatch` — 공용 함수로 꺼내는 리팩토링은 동작 무변경일 때만) — 예외는 ③ 트리거(선택 위치에서만 발화)와 ④ 새 API.
- **시각**: 만료 비교는 `:now`(앱 Clock · 요청 시작) — DB `now()`로 옮기지 않는다.
- **마이그레이션**: V12 · V13 기본 위치(추가형 · IF NOT EXISTS 금지 — 기존 중복이면 기동이 멈춰야 한다) · V14 선택 위치 `db/migration-confirm-version`. 거부된 기동은 스키마를 바꾸지 않는다(규칙 1~7은 `flyway.migrate()` 앞).
- **load-bearing 판정 뒤 재합의**: 재현 스모크 #1 결과가 §설계-1 '우연한 가드' 추정과 다르면 §문제 · §설계-2 기대 칸을 고치고 사용자에게 보고한다(선택지 4개 비교 범위는 그대로 — Q1 답).
