# ADR-007: 결제 성공 후 확정 실패 보상 (Q6 후속)

- 상태: 가설 (Hypothesis) — 미측정
- 대응 질문: Q6 후속
- 선행: ADR-006

## 문제

결제는 외부에서 이미 성공했는데 확정 트랜잭션이 실패하는 경우(결제 도중 홀드 만료 → 다른 사용자가 선점)가 있다. 돈은 빠졌고 좌석은 없다.

## 가설

- ADR-006로 중복 확정은 막아도, 확정 실패 건은 결제만 남은 고아 결제가 된다.

## 선택지 후보

- 즉시 환불(보상 트랜잭션) / 대체 좌석 제안 / 결제 전 홀드 연장으로 발생 자체를 줄이기
- 결제와 확정의 순서 역전: 확정 가능 여부를 먼저 잠그고 결제 (→ 02·03 랩과 경계)
- 고아 결제 탐지: 결제 uid는 있는데 확정 예약이 없는 건을 판정 기준(ADR-001)에 추가
