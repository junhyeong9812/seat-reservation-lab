# ADR-009: 연석 부분 선점 (Q2)
> 번호 이동(2026-10-04): 임계 구역 길이·락 보유 시간을 새 ADR-004로 넣으며 기존 ADR-004~010을 005~011로 옮겼다 — 이 문서의 번호 참조는 새 번호다.

- 상태: 가설 (Hypothesis) — 미측정
- 대응 질문: Q2 "2연석 중 1석만 선점에 성공했다면?"
- 선행: ADR-003

## 문제

기준선은 1회 1석만 선점한다. 연석(Load Profile 40%)을 1석씩 두 번 요청하면 첫 석만 잡히고 둘째 석을 뺏긴 사용자가 원치 않는 1석을 쥔다.

## 가설

- 2연석을 1석 API로 두 번 요청하면 부분 선점이 발생하고, 쥔 1석은 TTL 동안 아무에게도 안 팔린다.

## 선택지 후보

- 다석 선점 API: 한 트랜잭션에서 전부 아니면 전무(all-or-nothing)
- 락 획득 순서 고정(좌석 id 오름차순) — 두 사용자가 겹치는 연석을 반대 순서로 잡을 때의 교착 방지
- 예약 모델: 예약 1행 = 좌석 1석 vs 예약(헤더) + 예약좌석(라인) — 부분 취소·환불 단위와 함께 결정
