## 2. 경계·불변식 (필수)

- **M18-1 정합(합격 조건 — 회차마다)**
  - 부분 선점(묶음 홀드 수 ∉ {0, N}) 0.
  - 정합성 검증기 위반 필드 0(새 4필드 포함).
  - 예약 · 결제 대조: 이중 판매 0 · 돈 받고 좌석 없음 0(refund 보상 미완료 0) · 카운터 = 홀드 + 예약.
  - 5xx 0 — 단 경계 셀의 40P01은 따로 센다(M18-5).
- **M18-2 비교 지표(본 셀)**
  - 겹침 단계별 '2석을 다 잡은 사용자 비율'.
  - 두 요청이 모두 실패한 쌍의 비율(one-shot SKIP LOCKED 특성).
  - B0 · B1의 '첫 석만 잡은 횟수'(B0은 TTL까지 잡은 채 · B1은 놓기까지의 시간) · 그동안 그 좌석에 막힌 다른 사용자 수.
  - 선점 · 결제 시작 · 확정의 p50 · p99(허용 상한만 판정에 씀).
  - 동시 경합 셀(burst): 같은 순간에 보낸 묶음 안에서 2석 성공 수 · 모두 실패한 묶음 비율 · cause(nowait · short · rule) 분포 · 부분 선점 0 · 5xx · 40P01 0.
- **M18-3 무효 회차** — 판정에 넣지 않고 사유를 회차 폴더에 남긴다.
  - k6 연결 오류(dial · reset · timeout) 1건 이상.
  - 계획 세션 수 ≠ 분류 세션 수(조용한 누락 0).
  - 시드 대조 불일치.
  - 해석(2026-11-20 하네스 리뷰 — 정합성 먼저 Q4): '무효 회차는 판정에 넣지 않는다'는 측정 타당성(성공률 · p99)에만 적용한다. 무효 시도에서 관측된 정합 위반(G1)은 버리지 않고 캠페인에 남기며, 그런 방식은 통과로 판정하지 않는다. 앱 응답 계약 위반(예: 묶음 201에 좌석 1석)은 무효가 아니라 정합 실패다.
- 경계 셀 결론 규칙(2026-11-20): 경계 진입 · 만료 시각을 걸친 요청 수는 유효성 조건이 아니라 노출량으로 보고한다. '40P01 0'은 노출량과 함께만 결론에 쓴다.
- **M18-4 회차 격리** — DB · 앱 · PG 상태를 다른 회차와 나누지 않는다(compose down · 볼륨 초기화 · PG reset · 시드).
- **M18-5 경계 셀**
  - 만료 직전에 결제 시작 · 확정을 몰아 보낸다.
  - 결과로 40P01 · 500 수, 안전망 환불 수, 정합 위반 0을 센다.
  - 이 결과로 '카운터 행을 먼저 잡게 하는 수정'이 필요한지 정한다(필요하면 별도 작업으로).
- **M18-6 앱 기본 동작 무변경** — 지표 추가는 관측만 한다. 응답 · 상태 전이 · 잠금은 그대로다. 1석 경로의 기존 지표 이름 · 태그도 그대로다(ADR-015~017 하네스가 읽음).
- **M18-7 측정 전 고정** — 캠페인은 고정 커밋의 이미지 · 하네스 값으로만 돈다. 고정 뒤 값을 바꾸면 고정 커밋을 다시 만들고 사용자 확인을 받는다.

## 8. load-bearing 가정

1. **고정 도착률 20세션/초에서 겹침 단계(인기 구역 집중도)만으로 세 방식의 성공률 차이가 드러난다.**
   - 드러나지 않으면 단계 값 · 좌석 구성을 다시 정한다.
   - 실증: 로컬 → .164 스모크에서 단계별 성공률이 서로 다른지 본다.
2. **경계 셀이 만료 시각 경계(이쪽 now < E ≤ 배치 now)에 결제 시작 · 확정을 실제로 넣을 수 있다.**
   - 배치 주기와 TTL을 측정용으로 짧게 두는 설정 옵션이 필요할 수 있다(기존 설정 키만 쓴다).
   - 실증: 로컬 스모크에서 경계 진입 요청 수가 0이 아님을 본다.
